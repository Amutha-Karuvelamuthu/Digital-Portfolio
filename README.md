## Local Development

This is a static single-page site. To preview locally, simply open `index.html` in any browser — no build step required.

## Deployment

This site is deployed via **GitHub Pages**, serving directly from the `main` branch root. Any commit pushed to `main` automatically triggers a redeploy (visible under the **Actions** tab).
